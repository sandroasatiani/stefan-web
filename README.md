# Stefan Web Archive

A complete, self-contained offline archive of three websites:

1. **[Hotel Riho (hotelriho/)](hotelriho/index.html)**
   - Original: `https://www.hotelriho.com`
   - Welcome to Ushguli, Svaneti, Georgia

2. **[Villa Tiflis (villatiflis/)](villatiflis/index.html)**
   - Original: `https://www.villatiflis.com`
   - Guest house & Bed & Breakfast in Tbilisi, Georgia

3. **[Saftladen Film (saftladen-film/)](saftladen-film/index.html)**
   - Original: `https://www.saftladen-film.de`
   - Documentary film production site

---

### Features
- Every page is preserved with original layouts, styles, fonts, and photo galleries.
- All internal navigation links and asset paths have been rewritten to relative local URLs.
- Can be browsed locally without an active internet connection.
- Each site folder contains a standalone `.zip` archive for easy distribution.
